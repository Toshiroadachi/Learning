**加速度**とは「速さがどれだけ急に変わるか」です。

自転車でこぎ始めるとき、最初は 0 km/h、1秒後に 5 km/h、2秒後に 10 km/h…と、**毎秒同じだけ速くなる**とします。この「毎秒どれだけ速くなるか」が加速度です。

- 加速度が大きい ＝ スポーツカーのように、ぐんぐん速くなる
- 加速度が 0 ＝ 速さが変わらない（等速）
- 加速度がマイナス ＝ ブレーキをかけてだんだん遅くなる

速さが毎秒同じだけ変わる運動を **等加速度直線運動** と呼びます。高校物理の運動は、ほとんどこの形で考えます。

@detail
### 1. 加速度の定義
$$a = \frac{v - v_0}{t}$$
- $v_0$（ブイゼロ）：はじめの速さ
- $v$：$t$ 秒後の速さ
- 単位は **m/s²**（「メートル毎秒毎秒」＝ 1秒ごとに何 m/s 速くなるか）

例：0 m/s から 4秒後に 12 m/s → $a = \dfrac{12-0}{4} = 3$ m/s²（毎秒 3 m/s ずつ速くなる）

### 2. 速さの変化を表にすると
加速度 3 m/s²、はじめ 0 m/s：
| 時刻 t [s] | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 速さ v [m/s] | 0 | 3 | 6 | 9 | 12 |
1秒ごとに 3 ずつ増えています。これを式にすると $v = 0 + 3t$。一般には：
$$v = v_0 + at$$

### 3. 進んだ距離 ＝ v-t グラフの面積
速さが一定なら「距離 ＝ 速さ × 時間」（長方形の面積）。速さが変わるときも、**v-t グラフ（縦が速さ、横が時間）の下の面積が、進んだ距離** になります。

はじめ $v_0$、$t$ 秒後に $v_0 + at$ のグラフは台形です。
- 長方形の部分：$v_0 \times t$
- 三角形の部分：$\dfrac{1}{2} \times t \times at = \dfrac{1}{2}at^2$

合わせて：
$$x = v_0 t + \frac{1}{2}at^2$$

### 4. 時間を使わない式
上の2つの式から $t$ を消すと（計算は少し大変なので結果だけ覚えればOK）：
$$v^2 - v_0^2 = 2ax$$
「時間が問題に出てこない」ときに便利です。

### 5. どの式を使う？
| 分かっているもの → 求めたいもの | 使う式 |
|---|---|
| 時間 → 速さ | $v = v_0 + at$ |
| 時間 → 距離 | $x = v_0 t + \frac{1}{2}at^2$ |
| 時間が出てこない | $v^2 - v_0^2 = 2ax$ |
問題文から「分かっている量」に丸をつけて、どれも入っている式を選ぶのがコツです。

### 6. ブレーキ（減速）
ブレーキは「進む向きと逆向きの加速度」なので、**加速度をマイナス**にして同じ式を使います。止まるとき $v = 0$ です。

@formulas
- $v = v_0 + at$
- $x = v_0 t + \dfrac{1}{2}at^2$
- $v^2 - v_0^2 = 2ax$
- 加速度の単位は m/s²、減速は $a$ をマイナスに

@pitfalls
- **単位をそろえていない**：km/h は m/s に直す（36 km/h ＝ 10 m/s。km/h ÷ 3.6）
- **減速なのに a をプラスにする**：止まる運動は $a < 0$
- **$\frac{1}{2}$ を忘れる**：$x = v_0t + \frac12 at^2$ の $\frac12$
- **2乗の計算**：$at^2$ は「$a \times t \times t$」。$(at)^2$ ではない

@example
**例題** 静止していた電車が、加速度 0.50 m/s² で動き出した。20 秒後の速さと、その間に進んだ距離は？

**考え方**：はじめ止まっている → $v_0 = 0$。時間 $t = 20$ が分かっている。
1. 速さ：$v = v_0 + at = 0 + 0.50 \times 20 = 10$ m/s
2. 距離：$x = v_0t + \frac12 at^2 = 0 + \frac12 \times 0.50 \times 20^2 = \frac12 \times 0.50 \times 400 = 100$ m

**答え**：速さ 10 m/s、距離 100 m

ボールを落とすと、だんだん速くなりながら落ちていきます。これは地球がボールを引っぱっている（重力）からです。

空気の影響を考えなければ、**どんな物体も同じ加速度 9.8 m/s² で速くなりながら落ちます**。重いボールも軽いボールも同じです（月でハンマーと羽を落とすと同時に着く実験が有名です）。

この 9.8 m/s² を **重力加速度 $g$** と呼びます。落下運動は、前の単元の「等加速度直線運動」の $a$ を $g$ にしただけです。

@detail
### 1. 自由落下（そっと手を離す）
はじめの速さ 0、加速度 $g$（下向き）。下向きを正にして、前の単元の式の $a$ を $g$、$x$ を $y$ にするだけ：
$$v = gt, \qquad y = \frac{1}{2}gt^2, \qquad v^2 = 2gy$$

| 時刻 t [s] | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 速さ v [m/s] | 0 | 9.8 | 19.6 | 29.4 |
| 落ちた距離 y [m] | 0 | 4.9 | 19.6 | 44.1 |
速さは時間に比例、距離は時間の**2乗**に比例して増えます（2倍の時間で4倍の距離）。

### 2. 鉛直投げ上げ（真上に投げる）
上向きを正にすると、重力は**下向き**なので加速度は $-g$。
$$v = v_0 - gt, \qquad y = v_0 t - \frac{1}{2}gt^2, \qquad v^2 - v_0^2 = -2gy$$

動きの流れ：
| 場面 | 速さ v |
|---|---|
| 投げた瞬間 | $v_0$（上向き） |
| だんだん遅くなる | 減っていく |
| **最高点** | **0**（一瞬止まる） |
| 落ちてくる | マイナス（下向き） |

### 3. 最高点の求め方
最高点では $v = 0$。
- 最高点までの時間：$0 = v_0 - gt$ → $t = \dfrac{v_0}{g}$
- 最高点の高さ：$0 - v_0^2 = -2gH$ → $H = \dfrac{v_0^2}{2g}$

例：$v_0 = 19.6$ m/s → $t = 2.0$ s、$H = \dfrac{19.6^2}{2 \times 9.8} = 19.6$ m

### 4. 対称性
投げ上げた物体は、上がるのにかかった時間と同じ時間で元の高さに戻り、そのときの速さは投げた速さと同じ（向きは逆）です。

@formulas
- 自由落下：$v = gt$、$y = \frac12 gt^2$、$v^2 = 2gy$
- 投げ上げ（上向き正）：$v = v_0 - gt$、$y = v_0t - \frac12 gt^2$
- 最高点：$v = 0$、$t = v_0/g$、$H = v_0^2/(2g)$
- $g = 9.8$ m/s²

@pitfalls
- **向き（符号）を決めずに式を使う**：最初に「上向きを正」などと決める
- **最高点で加速度も 0 だと思う**：止まるのは速さだけ。加速度は常に $g$（下向き）
- **重いほど速く落ちると思う**：空気抵抗を考えなければ同じ
- **距離は時間に比例と思う**：落ちた距離は $t^2$ に比例

@example
**例題** ビルの屋上から小石を静かに落とした。3.0 秒後に地面に着いた。屋上の高さは？　$g = 9.8$ m/s²

**考え方**：静かに落とす ＝ 自由落下。時間が分かっていて距離を求める → $y = \frac12 gt^2$
$$y = \frac12 \times 9.8 \times 3.0^2 = 4.9 \times 9.0 = 44.1 ≒ 44 \text{ m}$$

物体にはいろいろな **力** がはたらいています。机の上の本にも、
- 地球が下に引っぱる力（**重力**）
- 机が上に押し返す力（**垂直抗力**）

がはたらいていて、2つの力が**引っぱり合いで引き分け**（つりあい）になっているから、本は動かないのです。

綱引きで、両チームが同じ力で引くと綱が動かないのと同じです。物理では「動かない物体には、合計で 0 になるように力がはたらいている」と考えて、見えない力の大きさを計算します。

@detail
### 1. よく出る力
| 力 | 向き | 大きさ |
|---|---|---|
| 重力 | 真下 | $W = mg$（質量 × 9.8） |
| 垂直抗力 $N$ | 面から垂直に押し返す | つりあいから求める |
| 張力 $T$ | 糸が引っぱる向き | つりあいから求める |
| 弾性力（ばね） | ばねが元に戻ろうとする向き | $F = kx$（フックの法則） |
単位はすべて **N（ニュートン）**。1 kg の物体の重力は $1 \times 9.8 = 9.8$ N。

### 2. 力を見つける手順
1. 注目する物体を1つ決める
2. **重力**を描く（必ずある）
3. その物体に**触れているもの**から受ける力を描く（床 → 垂直抗力、糸 → 張力、ばね → 弾性力）
4. 触れていないものからの力は、重力（と電気・磁気の力）だけ

### 3. つりあいの式
力が「上下」だけなら：**上向きの力の合計 ＝ 下向きの力の合計**
例：床の上の 2.0 kg の箱 → $N = mg = 2.0 \times 9.8 = 19.6$ N

### 4. フックの法則
ばねを $x$ [m] 伸ばすと、ばねは $F = kx$ の力で元に戻ろうとします（$k$ ＝ばね定数、単位 N/m）。
例：$k = 50$ N/m のばねに 0.50 kg のおもりをつるす → つりあい $kx = mg$ → $50x = 4.9$ → $x = 0.098$ m（9.8 cm）

### 5. 斜めの力は分解する
斜面の上の物体の重力 $mg$ は、
| 方向 | 成分 |
|---|---|
| 斜面に沿って下向き | $mg\sin\theta$ |
| 斜面に垂直 | $mg\cos\theta$ |
に分けて考えます。斜面に垂直な方向のつりあいから $N = mg\cos\theta$。
（30° なら $\sin 30° = \frac12$、$\cos 30° = \frac{\sqrt3}{2}$）

@formulas
- 重力 $W = mg$
- フックの法則 $F = kx$
- つりあい：（ある方向の）力の合計 ＝ 0
- 斜面：$mg\sin\theta$（斜面方向）、$mg\cos\theta$（垂直方向）

@pitfalls
- **質量と重さ（重力）の混同**：質量 2.0 kg の重力は 19.6 N
- **触れていないのに力を描く**：手で押していなければ「押す力」はない
- **ばねの伸び x を cm のまま**：m に直す
- **斜面で sin と cos を逆にする**：斜面に沿った成分が sin（角度が0なら0になる方）

@example
**例題** 質量 3.0 kg のおもりを、ばね定数 98 N/m のばねにつるして静止させた。ばねの伸びは何 m か。$g = 9.8$ m/s²

**考え方**：おもりにはたらく力は、重力（下向き $mg$）とばねの弾性力（上向き $kx$）。止まっているのでつりあい。
$$kx = mg \;\Rightarrow\; 98x = 3.0 \times 9.8 = 29.4 \;\Rightarrow\; x = 0.30 \text{ m}$$

「重いものほど動かしにくい」「強く押すほど速く加速する」── 誰でも経験で知っているこの2つを、1本の式にまとめたのが **運動方程式** です。
$$ma = F$$
- $m$（質量）が大きいほど、同じ力でも加速しにくい
- $F$（力）が大きいほど、ぐんぐん加速する

ショッピングカートを押すとき、空のカートは軽く押しただけで加速し、荷物満載のカートは同じ力では少ししか加速しない ── これを数字で計算できるのが、この式のすごいところです。

@detail
### 1. 運動方程式の意味
$$ma = F$$
- $m$：質量 [kg]
- $a$：加速度 [m/s²]
- $F$：物体にはたらく **力の合計（合力）** [N]
1 N は「1 kg の物体に 1 m/s² の加速度を生じさせる力」です。

### 2. 使い方の手順
1. 注目する物体を決める
2. はたらく力をすべて描く（重力・垂直抗力・張力・摩擦…）
3. 運動する向き（加速度の向き）を正とする
4. その向きの力の合計を $F$ として $ma = F$ を立てる

### 3. 例：ひもで引き上げる
質量 2.0 kg のおもりを、ひもで上向きに 29.6 N で引き上げる（上向き正）。
| 力 | 向き | 大きさ |
|---|---|---|
| 張力 | 上 | 29.6 N |
| 重力 | 下 | $2.0 \times 9.8 = 19.6$ N |
合力 $F = 29.6 - 19.6 = 10$ N（上向き）
$$2.0a = 10 \;\Rightarrow\; a = 5.0 \text{ m/s}^2$$

### 4. 2つの物体がつながっているとき
なめらかな床の上で、A（3.0 kg）と B（2.0 kg）をひもでつなぎ、A を 10 N で引く。
- まとめて1つと考える：$(3.0 + 2.0)a = 10$ → $a = 2.0$ m/s²
- B だけに注目：B を引いているのはひもの張力 $T$ だけ → $2.0 \times 2.0 = T$ → $T = 4.0$ N

「全体で加速度」→「1つずつで内部の力」の順に考えると楽です。

### 5. 作用・反作用
A が B を押すと、B も A を **同じ大きさで逆向き** に押し返します（作用・反作用の法則）。上の例でも、ひもは A を後ろに 4.0 N、B を前に 4.0 N で引いています。

### 6. 慣性の法則
力がはたらかない（合力が 0）なら $a = 0$。止まっている物体は止まったまま、動いている物体は同じ速さでまっすぐ進み続けます。

@formulas
- 運動方程式 $ma = F$（$F$ は合力）
- 1 N ＝ 1 kg·m/s²
- 作用・反作用：同じ大きさ・逆向き・別の物体にはたらく

@pitfalls
- **F に重力を入れ忘れる**：上下の運動では必ず重力も合力に入れる
- **合力ではなく1つの力だけで計算**：$F$ は「その向きの力の合計」
- **つりあいと作用・反作用の混同**：つりあいは「1つの物体」にはたらく力、作用・反作用は「2つの物体」の間の力
- **質量 g（グラム）のまま計算**：kg に直す

ジェットコースターは、最初に高いところまで引き上げられた後は、エンジンなしで坂を下ったり上ったりします。どうして走り続けられるのでしょう？

それは、**高さのエネルギー（位置エネルギー）** と **速さのエネルギー（運動エネルギー）** が、お互いに入れかわっているからです。
- 坂を下る → 高さが減る分、速くなる
- 坂を上る → 速さが減る分、高くなる

摩擦がなければ、2つの合計はずっと同じ。これを **力学的エネルギー保存の法則** と呼びます。お金にたとえると、「財布（高さ）」と「銀行（速さ）」の間でお金を移しているだけで、合計額は変わらない、という感じです。

@detail
### 1. 2種類のエネルギー
| エネルギー | 式 | 意味 |
|---|---|---|
| 運動エネルギー | $K = \dfrac12 mv^2$ | 速いほど大きい（速さの2乗） |
| 重力の位置エネルギー | $U = mgh$ | 高いほど大きい |
| 弾性エネルギー（ばね） | $U = \dfrac12 kx^2$ | 縮める・伸ばすほど大きい |
単位はすべて **J（ジュール）**。

### 2. 保存の法則
摩擦や空気抵抗がなければ：
$$\frac12 mv^2 + mgh = \text{一定}$$
「はじめの合計 ＝ あとの合計」の式を立てるだけで、途中の複雑な動きを考えなくても速さが分かります。

### 3. 例：坂を下るボール
高さ 5.0 m の位置から静かに転がした（摩擦なし）。一番下での速さは？

|---|---|---|---|
| 上（静止） | $m \times 9.8 \times 5.0$ | 0 | $49m$ |
| 下（高さ0） | 0 | $\frac12 mv^2$ | $\frac12 mv^2$ |
$$\frac12 mv^2 = 49m \;\Rightarrow\; v^2 = 98 \;\Rightarrow\; v = 9.9 \text{ m/s}$$
**質量 $m$ が消える** ので、質量が分からなくても解けます。坂の形にも関係ありません。

### 4. ばねの場合
ばね定数 $k$ のばねを $x$ 縮めて物体を押し出す：
$$\frac12 kx^2 = \frac12 mv^2$$

### 5. 摩擦があるとき
摩擦があると、力学的エネルギーの一部が熱に変わって減ります。
$$\text{（あとの力学的エネルギー）} = \text{（はじめ）} - \text{（摩擦力がした仕事の大きさ）}$$

@formulas

ビリヤードで、止まっている球に同じ重さの球をまっすぐ当てると、ぶつけた球はピタッと止まり、当てられた球が同じ速さで走り出します。まるで「勢い」がそっくり受け渡されたようです。

この「勢い」を物理では **運動量**（質量 × 速度）と呼びます。ぶつかり合う物体どうしの間では、**運動量の合計は変わりません**（運動量保存の法則）。衝突の途中でどんなに複雑な力がはたらいても、前と後の運動量の合計だけで、衝突後の速さが計算できます。

@detail
### 1. 運動量
$$p = mv$$
- 単位は kg·m/s
- 速度と同じく**向き**がある（右を正なら、左向きの運動量はマイナス）
例：2.0 kg の球が右に 3.0 m/s → $p = 6.0$ kg·m/s

### 2. 運動量保存の法則
2つの物体 A, B がぶつかるとき（外から力がはたらかなければ）：
$$m_A v_A + m_B v_B = m_A v_A' + m_B v_B'$$
（' はぶつかった後の速度）

### 3. 例：合体する衝突
右に 4.0 m/s で進む 2.0 kg の台車 A が、止まっている 2.0 kg の台車 B にぶつかってくっついた。
| | A の運動量 | B の運動量 | 合計 |
|---|---|---|---|
| 前 | $2.0 \times 4.0 = 8.0$ | 0 | 8.0 |
| 後（一緒に $V$） | $2.0V$ | $2.0V$ | $4.0V$ |
$$4.0V = 8.0 \;\Rightarrow\; V = 2.0 \text{ m/s}$$

### 4. 向きに注意（逆向きの衝突）
右に 3.0 m/s の 1.0 kg と、左に 1.0 m/s の 2.0 kg がぶつかる。右を正にすると、左向きの速度は **−1.0**。
前の合計：$1.0 \times 3.0 + 2.0 \times (-1.0) = 1.0$ kg·m/s

### 5. 反発係数（はねかえり係数）
$$e = -\frac{v_A' - v_B'}{v_A - v_B}$$
「離れる速さ ÷ 近づく速さ」。
| e | 衝突の種類 |
|---|---|
| 1 | 弾性衝突（エネルギーも保存。ビリヤードはほぼこれ） |
| 0〜1 | 非弾性衝突 |
| 0 | 完全非弾性衝突（くっつく） |
運動量保存の式と反発係数の式の **2本を連立** すれば、衝突後の2つの速度が求まります。

### 6. 分裂（打ち出し）
止まっている物体が2つに分かれる（大砲の発射、ボートからの飛び降り）ときも、前の運動量は 0 なので、後の合計も 0。2つは逆向きに飛びます。

@formulas
- 運動量 $p = mv$（向きあり）
- 保存則 $m_Av_A + m_Bv_B = m_Av_A' + m_Bv_B'$
- 反発係数 $e = -\dfrac{v_A' - v_B'}{v_A - v_B}$
- くっつく → $e = 0$、弾性衝突 → $e = 1$

@pitfalls
- **向き（符号）を無視する**：逆向きの速度はマイナス
- **運動エネルギーも保存すると思い込む**：保存するのは弾性衝突（$e = 1$）のときだけ
- **反発係数の式のマイナスを忘れる**
- **くっついた後の質量**：2つの質量の合計

@example

ハンマー投げの選手がハンマーを振り回すと、ハンマーは円を描いて回ります。このとき選手は、ワイヤーで**ハンマーを円の中心向きに引っぱり続けて**います。手を離すと、ハンマーはその瞬間に進んでいた方向へまっすぐ飛んでいきます。

つまり、円運動を続けるには「中心向きの力」が必要です。これを **向心力** と呼びます。車がカーブを曲がれるのはタイヤと道路の摩擦が、月が地球の周りを回れるのは地球の引力が、向心力になっているからです。

@detail
### 1. 回る速さの表し方
| 量 | 記号 | 意味 | 単位 |
|---|---|---|---|
| 速さ | $v$ | 円周に沿って進む速さ | m/s |
| 角速度 | $\omega$ | 1秒あたりに回る角度 | rad/s |
| 周期 | $T$ | 1周にかかる時間 | s |
| 回転数 | $n$ | 1秒あたりに回る回数 | Hz（回/s） |
1周は $2\pi$ rad（＝360°）なので：
$$v = r\omega, \qquad T = \frac{2\pi r}{v} = \frac{2\pi}{\omega}, \qquad n = \frac{1}{T}$$

### 2. 向心加速度
速さが一定でも、**向きが変わり続ける** ので加速度があります。向きは常に円の中心。
$$a = \frac{v^2}{r} = r\omega^2$$

### 3. 向心力（中心向きの運動方程式）
$$m\frac{v^2}{r} = F \qquad （F は中心向きの力の合計）$$
例：長さ 0.50 m の糸に 0.20 kg のおもりをつけ、なめらかな水平面上で 2.0 m/s で回す。糸の張力は？
$$T = m\frac{v^2}{r} = 0.20 \times \frac{2.0^2}{0.50} = 1.6 \text{ N}$$

### 4. 何が向心力になっているか
| 場面 | 向心力の正体 |
|---|---|
| 糸につけた石を回す | 糸の張力 |
| 車がカーブを曲がる | 路面の摩擦力 |
| 人工衛星・月 | 万有引力 |
| ジェットコースターの宙返り | 重力 ＋ レールの垂直抗力 |
「向心力」という特別な力があるのではなく、**中心向きの力の合計** を向心力と呼んでいるだけです。

### 5. 慣性力（遠心力）
回っている人（一緒に回る立場）から見ると、外向きに引っぱられるように感じます。これが **遠心力** $m\dfrac{v^2}{r}$ です。外から見る立場では「向心力」、一緒に回る立場では「遠心力とのつりあい」と、どちらか一方で考えます（混ぜないこと）。

@formulas
- $v = r\omega$、$T = \dfrac{2\pi r}{v} = \dfrac{2\pi}{\omega}$
- 向心加速度 $a = \dfrac{v^2}{r} = r\omega^2$
- 運動方程式 $m\dfrac{v^2}{r} = F$（中心向き）

@pitfalls
- **向心力を別の力として描き足す**：張力や摩擦が向心力そのもの
- **遠心力と向心力を両方描く**：立場を1つに決める
- **半径と直径の取り違え**
- **角度を度のまま使う**：ω は rad/s（1周 ＝ $2\pi$）

@example
**例題** 半径 2.0 m の円周上を、周期 4.0 秒で等速円運動する物体の速さと角速度は？（$\pi = 3.14$）

**考え方**：1周の長さ $2\pi r$ を周期で割る。
$$v = \frac{2\pi r}{T} = \frac{2 \times 3.14 \times 2.0}{4.0} = 3.14 \text{ m/s}, \qquad \omega = \frac{2\pi}{T} = 1.57 \text{ rad/s}$$

@solution

@problem n=4 type=num ans=10 unit=m/s tol=0.02 lv=2 calc=sqrt(0.50*9.8*20.4)
水平な道路の、半径 20.4 m のカーブを車が曲がる。タイヤと路面の静止摩擦係数を 0.50 とすると、すべらずに曲がれる最大の速さは何 m/s か。$g = 9.8$ m/s²
@hint
向心力 ＝ 摩擦力。最大摩擦力は $\mu mg$。$m\dfrac{v^2}{r} = \mu mg$。
@solution
1. $m\dfrac{v^2}{r} = \mu mg$ → $v^2 = \mu g r$（$m$ が消える）
2. $v^2 = 0.50 \times 9.8 \times 20.4 = 99.96$
3. $v ≒ 10$
4. 答え：**約 10 m/s**（時速 36 km）

@problem n=5 type=num ans=7.0 unit=m/s tol=0.02 lv=3 calc=sqrt(9.8*5.0)
【ボス問題】半径 5.0 m の円形のレールの内側を、小球が宙返りする。最高点でレールから離れないためには、最高点での速さは少なくとも何 m/s 必要か。$g = 9.8$ m/s²
@hint
最高点では、重力 $mg$ と垂直抗力 $N$ がどちらも下（中心）向き。$m\dfrac{v^2}{r} = mg + N$。離れないギリギリは $N = 0$。
@solution
1. 最高点の運動方程式（中心向き）：$m\dfrac{v^2}{r} = mg + N$
2. 離れない条件 $N \ge 0$ → $m\dfrac{v^2}{r} \ge mg$ → $v^2 \ge gr$
3. $v^2 \ge 9.8 \times 5.0 = 49$ → $v \ge 7.0$
4. 答え：**7.0 m/s**

電気回路は **水の流れ** にたとえると分かりやすくなります。
| 電気 | 水 |
|---|---|
| 電圧 $V$ | 水を押し出すポンプの強さ（高さの差） |
| 電流 $I$ | 流れる水の量 |
| 抵抗 $R$ | 細いパイプ（流れにくさ） |
ポンプが強いほどたくさん流れ、パイプが細いほど流れにくい ── これを式にしたのが **オームの法則** $V = RI$ です。

@detail
### 1. オームの法則
$$V = RI$$
- $V$：電圧 [V ボルト]
- $I$：電流 [A アンペア]
- $R$：抵抗 [Ω オーム]
例：10 Ω の抵抗に 2.0 A 流れているとき、電圧は $10 \times 2.0 = 20$ V

### 2. 直列つなぎ（1本道）
| 量 | 性質 |
|---|---|
| 電流 | どこでも同じ |
| 電圧 | 分かれる（足すと全体の電圧） |
| 合成抵抗 | $R = R_1 + R_2$（足し算） |
細いパイプを2本つなぐと、もっと流れにくくなるイメージです。

### 3. 並列つなぎ（枝分かれ）
| 量 | 性質 |
|---|---|
| 電圧 | どの枝も同じ |
| 電流 | 分かれる（足すと全体の電流） |
| 合成抵抗 | $\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2}$ |
パイプを並べると、水の通り道が増えて流れやすくなる（合成抵抗は小さくなる）イメージです。
2つなら $R = \dfrac{R_1R_2}{R_1 + R_2}$（和分の積）。例：6 Ω と 3 Ω → $\dfrac{18}{9} = 2$ Ω

### 4. 解き方の手順
1. 合成抵抗を求める
2. オームの法則で全体の電流 $I = V/R$
3. 直列部分は電流が同じ、並列部分は電圧が同じ、を使って各部分を求める

### 5. 抵抗率
長さ $L$、断面積 $S$ の導線の抵抗：
$$R = \rho\frac{L}{S}$$
長いほど大きく、太いほど小さい（パイプと同じ）。

@formulas
- $V = RI$
- 直列 $R = R_1 + R_2$
- 並列 $\dfrac1R = \dfrac1{R_1} + \dfrac1{R_2}$（2つなら $\dfrac{R_1R_2}{R_1+R_2}$）
- 抵抗率 $R = \rho \dfrac{L}{S}$

@pitfalls
- **並列の合成抵抗を足し算してしまう**：並列は逆数の和
- **並列で最後に逆数に戻し忘れる**：$\frac1R = \frac12$ なら $R = 2$
- **mA のまま計算**：1 mA ＝ 0.001 A
- **直列と並列の性質の取り違え**：直列は電流が同じ、並列は電圧が同じ

@example
**例題** 4.0 Ω と 6.0 Ω の抵抗を直列につなぎ、20 V の電池につないだ。流れる電流と、4.0 Ω の抵抗にかかる電圧は？

**考え方**：直列なので合成抵抗は足し算。
1. $R = 4.0 + 6.0 = 10$ Ω
2. $I = 20 \div 10 = 2.0$ A（どこでも同じ）
3. 4.0 Ω の電圧：$4.0 \times 2.0 = 8.0$ V

@hint

@solution
1. $I = 6.0 \div 12 = 0.50$
2. 答え：**0.50 A**
