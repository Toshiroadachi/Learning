# TOEIC 900 Trainer

TOEIC L&R 900点を目指すための学習Webアプリ（スマホ対応・インストール不要・サーバー不要）。

## 主な機能

| 機能 | 内容 |
|---|---|
| **予想スコア** | パートごとの正答率（最近の解答ほど重視）を本番の問題数に当てはめ、L/R別の換算点・合計点・幅を表示。解答が少ない間は自己申告スコアで補完 |
| **おすすめ学習** | 目標スコアに必要な各パートの正答率との差 ×問題数から「伸びしろ点数」を計算し、優先パートと弱点カテゴリ（文法項目・設問タイプ）を提示 |
| **Part 1〜7 手動選択** | 問題数・難易度・出題順（おすすめ／未解答優先／ランダム）を選んで練習 |
| **リスニング** | ブラウザの音声合成で読み上げ（米・英・豪・加の発音をローテーション、速度調整可） |
| **シャドーイング** | Part 3/4 の解答後にスクリプトを表示し、1文ずつ再生・0.75倍再生 |
| **時間管理** | Part 5 は1問20秒（変更可）、Part 6/7 は所要時間を表示 |
| **復習** | 間違えた問題を間隔反復（1→3→7→16→35日）で自動出題 |
| **ミニ模試** | 全パートから約45問 → 換算スコアを記録 |
| **単語** | 900点レベルの頻出語150語を間隔反復のフラッシュカードで学習 |
| **海外ニュース** | BBC / NPR / Guardian / Al Jazeera / CNBC の見出し・要約を **毎朝自動更新**。単語タップで意味表示・単語帳保存、TOEIC頻出語をハイライト、読み上げ |
| **毎日のスケジュール** | 単語・Part5・リスニング・シャドーイング・Part7・復習・ニュースのチェックリスト（自由に編集可）。アプリ内で解いた量を自動カウント、連続達成日数を表示 |
| **記録** | 予想スコアの推移グラフ、14日カレンダー、弱点カテゴリ表、模試履歴 |
| **AI問題生成（任意）** | Claude API キーを設定すると、弱点とレベルに合わせた新作問題を無制限に生成。ニュース記事の日本語解説＋理解度クイズも |

学習データはブラウザの localStorage に保存されます（設定画面からバックアップの書き出し・読み込みが可能）。

## 使い方

### GitHub Pages で公開（推奨・スマホから使える）

1. このブランチを `main` にマージ
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定
3. `Deploy to GitHub Pages` ワークフローが走り、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります
4. スマホのブラウザで開き「ホーム画面に追加」するとアプリのように使えます

### ニュースの毎日更新

`.github/workflows/news.yml` が毎朝 6:17（日本時間）に RSS を取得し、`data/news.json` を更新してコミットします。
その後 Pages が自動で再デプロイされます。Actions タブの **Update daily news → Run workflow** で手動実行も可能です。
（記事本文は転載せず、見出し・要約・元記事リンクのみを保存しています）

取得元を変えたい場合は `scripts/fetch-news.mjs` の `FEEDS` を編集してください。

### ローカルで動かす

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
node scripts/fetch-news.mjs   # ニュースを手動で取得
```

## 構成

```
index.html / css/style.css / sw.js     画面・スタイル・オフライン対応
js/app.js       画面とクイズの処理
js/score.js     予想スコア・おすすめパートの計算
js/storage.js   保存・間隔反復
js/speech.js    音声読み上げ
js/ai.js        Claude API（任意機能）
data/p1〜p7.js  問題データ（オリジナル問題）
data/vocab.js   単語データ
scripts/fetch-news.mjs  ニュース取得スクリプト
```

問題を追加したい場合は `data/pX.js` に同じ形式で追記してください（`answer` は選択肢の0始まりの番号。表示時は自動でシャッフルされます）。

## 注意

- 予想スコアは公式の換算表（非公開）ではなく近似値です。目安として使ってください。
- 音声はブラウザ・端末の合成音声を使います（iPhone の Safari / Android の Chrome で動作）。
- AI 機能の API キーはこの端末にのみ保存され、Anthropic API への直接通信にだけ使われます。利用料金は従量課金です。
