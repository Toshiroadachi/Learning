**関数**は「料理のレシピに名前を付けたもの」です。「カレーの作り方」を一度書いておけば、次からは「カレーを作って」と言うだけで済みます。同じ処理を何度も書かずに済み、プログラムが読みやすくなります。

**while ループ**は「〜の間、くり返す」。for が「10回くり返す」「リストの全員に」のように**回数が決まっている**ときに使うのに対し、while は「正解するまで」「目標額に届くまで」のように**何回になるか分からない**ときに使います。

@detail
### 1. 関数を作る（定義）と使う（呼び出し）
```python
def greet():
    print("おはよう")
    print("今日もがんばろう")

greet()
greet()
```
▶ 実行結果
```
おはよう
今日もがんばろう
おはよう
今日もがんばろう
```
- `def 関数名():` で「これからレシピを書きます」という宣言。行末のコロンを忘れずに
- インデントした行が関数の中身
- **def を書いただけでは何も起きません**。`greet()` と呼び出したときに初めて中身が実行されます
- 呼び出しは定義より**後ろ**に書く（Python は上から読むので、先に呼ぶと「そんな関数はない」とエラー）

### 2. 関数の中で関数を使う
```python
def turn_left():
    print("左を向く")

def turn_right():
    turn_left()        # 左を3回向けば、右を向いたのと同じ
    turn_left()
    turn_left()

turn_right()
```
小さな関数を組み合わせて、大きな動きを作れます。turn_right() を呼ぶと、中で turn_left() が3回呼ばれます。

### 3. while — 条件が True の間くり返す
```python
n = 3
while n > 0:
    print(n)
    n -= 1          # これを忘れると n がずっと 3 のまま → 無限ループ
print("発射！")
```
| 回目 | 条件 n > 0 の判定 | 表示 | n（ブロックの後） |
|---|---|---|---|
| 1 | 3 > 0 → True | 3 | 2 |
| 2 | 2 > 0 → True | 2 | 1 |
| 3 | 1 > 0 → True | 1 | 0 |
| 4 | 0 > 0 → **False** | ループ終了 → 発射！ | |

while は**毎回、ブロックの最初に条件を確認**します。条件が False になった時点で、ループの後ろの行へ進みます。

### 4. 数を数えながら目標まで（貯金の例）
```python
goal = 10000
saved = 0
months = 0
while saved < goal:      # 目標に届いていない間
    saved += 3000
    months += 1
print(f"{months}か月で達成")    # 4か月で達成
```
「何か月かかるか」は最初は分からない ── これが while の出番です。

### 5. while True と break — 「正解するまで聞く」
```python
count = 0
while True:                  # 条件がいつも True → ずっとくり返す
    count += 1
    answer = int(input("7 × 8 = ? "))
    if answer == 56:
        break                # ← ループを抜ける
    print("ちがいます")
print(f"正解！ {count}回目で正解しました")
```
`break` はループを途中で終わらせる命令です。`while True:` と組み合わせると「ある条件になったら抜ける」ループを書けます。

> 無限ループになっても、このアプリでは約12秒で自動停止します。慌てなくて大丈夫です。

@pitfalls
- **呼び出しの () を忘れる** `greet` だけでは実行されない。`greet()`
- **定義の前に呼び出す** → NameError。def を上に書く
- **while の中で値を変え忘れる** 条件がずっと True のまま → 無限ループ
- **カウンターの初期化位置** `months = 0` は while の前に。中に書くと毎回 0 に戻る
- **break の位置** if の中（インデントを1段深く）に書く。if の外に書くと1回目で必ず抜けてしまう

今日はこれまでの道具（変数・if・for・while・リスト・random）を**組み合わせて1つのゲーム**を作ります。

大事なのは「いきなり全部書かない」こと。料理で言えば、①材料を切る ②炒める ③味付け…と工程に分けるように、ゲームも**小さな部品に分けて、1つずつ動かしながら**作ります。プロのプログラマーも同じやり方をしています。

@detail
### 1. 全体の流れを日本語で書く
```
答え = "python"、ライフ = 3
伏せ字 = _ _ _ _ _ _
（全部当てていない かつ ライフが残っている）間くり返す:
    伏せ字を表示
    1文字聞く
    当たり → その位置を公開
    はずれ → ライフ -1、残りライフを表示
勝ち/負けを表示
```
これを1行ずつ Python に置き換えていきます。

### 2. 部品①：伏せ字を作る
```python
word = "python"
display = ["_"] * len(word)    # ["_"] を6回くり返したリスト
print(display)                 # ['_', '_', '_', '_', '_', '_']
print(" ".join(display))       # _ _ _ _ _ _
```
文字列は一部だけ書き換えられないので、**リスト**にしておくのがコツです。

### 3. 部品②：当たった位置を公開する
```python
guess = "t"
for i in range(len(word)):        # i = 0, 1, 2, 3, 4, 5
    if word[i] == guess:          # i 番目の文字が予想と同じなら
        display[i] = guess        # 伏せ字の同じ位置を書き換える
print(" ".join(display))          # _ _ t _ _ _
```
`for i, ch in enumerate(word):` と書くと、番号 i と文字 ch を同時に取り出せます（同じ意味）。

### 4. 部品③：当たり・はずれの判定
```python
if guess in word:        # 単語にその文字が含まれているか
    ...公開する...
else:
    lives -= 1
    print(f"はずれ！残りライフ {lives}")
```

### 5. 部品④：ループと終わり方
```python
while "_" in display and lives > 0:
    ...
```
「まだ伏せ字が残っている」**かつ**「ライフが残っている」間だけ続けます。どちらかが成り立たなくなったらループを抜けるので、**ループの後で**どちらの理由で終わったかを調べます。
```python
if "_" not in display:
    print(f"正解！ {word}")
else:
    print(f"ゲームオーバー 答えは {word}")
```

### 6. 改良：同じ文字の二度押し
予想した文字をリスト `guessed` に記録しておき、もう一度来たら注意だけしてやり直させます。
```python
guessed = []
...
    guess = input("1文字: ")
    if guess in guessed:
        print("すでに予想した文字です")
        continue                 # ← ループの先頭に戻る（下の処理を飛ばす）
    guessed.append(guess)
```
`continue` は「今回の残りを飛ばして、次の回へ」。`break`（ループを抜ける）との違いに注意。

@pitfalls
- **文字列の一部を直接書き換えようとする** `word[0] = "x"` は TypeError。書き換えるものはリストに
- **join し忘れ** `print(display)` だと `['_', '_']` のように表示される。`" ".join(display)`
- **勝敗の表示をループの中に書く** 終わったかどうかはループの後で判定
- **ライフの減らし忘れ** はずれのときに `lives -= 1` がないと終わらない
- **break と continue の取り違え** 二度押しで break すると、ゲームが終わってしまう

Day 6 の関数は、いつも同じことしかできませんでした。**引数**を使うと、関数に**材料を渡して、毎回違う結果**を出せるようになります。

自動販売機にたとえると、関数が自販機、引数が「入れるお金と押すボタン」です。同じ自販機でも、押すボタンによって出てくる飲み物が変わります。

@detail
### 1. 引数を1つ受け取る関数
```python
def greet(name):
    print(f"{name}さん、こんにちは")

greet("たろう")
greet("はなこ")
```
▶ 実行結果
```
たろうさん、こんにちは
はなこさん、こんにちは
```
`greet("たろう")` と呼ぶと、関数の中では `name = "たろう"` が自動で行われたのと同じ状態で中身が実行されます。
- 関数側の `name` を**パラメータ**（受け取る変数）
- 呼び出し側の `"たろう"` を**引数**（渡す値）
と呼びます（日常的には両方「引数」と呼ぶことも多いです）。

### 2. 引数を複数受け取る
```python
def introduce(name, age):
    print(f"{name}、{age}歳です")

introduce("たろう", 20)      # name="たろう", age=20（順番で対応 → 位置引数）
introduce(age=30, name="はなこ")   # 名前で指定 → キーワード引数（順番は自由）
```
位置引数は**順番が大事**です。`introduce(20, "たろう")` と書くと「20、たろう歳です」になってしまいます。

### 3. デフォルト値（省略したときの値）
```python
def greet(name, time="朝"):
    print(f"{name}さん、{time}ですね")

greet("たろう")          # たろうさん、朝ですね   ← time を省略 → "朝"
greet("はなこ", "夜")    # はなこさん、夜ですね
```

### 4. 値を返す関数（return）— 次の Day 10 の予習
計算結果を呼び出し元に**返す**には `return` を使います。
```python
import math

def paint_cans(height, width, coverage=5):
    area = height * width            # 壁の面積
    return math.ceil(area / coverage)   # 切り上げた缶数を返す

print(paint_cans(3, 9))     # 27 / 5 = 5.4 → 6
```
- `math.ceil(5.4)` → 6（**切り上げ**。0.4缶分でも1缶買う必要がある）
- `math.floor(5.9)` → 5（切り捨て）

### 5. 文字を「ずらす」考え方（シーザー暗号）
```python
alphabet = "abcdefghijklmnopqrstuvwxyz"
i = alphabet.index("c")      # 2
print(alphabet[i + 3])       # f   ← 3つ後ろ
```
問題は "y" や "z" のように最後の方の文字です。"y"（24）+ 3 = 27 は範囲外。そこで **% 26（26で割った余り）** を使います。
```python
print((24 + 3) % 26)         # 1 → "b"
```
27 ÷ 26 = 1 余り 1 なので 1。ちょうど時計の針が12を過ぎると1に戻るのと同じで、**z の次は a に一周**します。マイナス方向（復号）でも Python の % は 0〜25 に収めてくれます。

### 6. 1文字ずつ処理して新しい文字列を作る
```python
result = ""
for ch in "hello!":
    if ch in alphabet:
        result += alphabet[(alphabet.index(ch) + 3) % 26]
    else:
        result += ch            # 記号や空白はそのまま
print(result)                   # khoor!
```

@pitfalls
- **引数の数が合わない** `greet()` → TypeError: missing 1 required positional argument
- **位置引数の順番を間違える** 定義の順番どおりに渡す（心配ならキーワード引数で）
- **return と print の混同** 演習で「返す」と書かれていたら return。print では採点の関数呼び出しで値が受け取れない
- **% 26 の付け忘れ** "x" "y" "z" で IndexError
- **素数判定で 1 を素数にしてしまう** 2 未満は先に False

**辞書（dict）**は、まさに国語辞典です。「見出し語（キー）」を引くと「意味（値）」が分かります。

リストは「0番、1番…」と**番号で**取り出しましたが、辞書は「"たろう" の点数は？」のように**名前（キー）で**取り出します。名簿・設定・成績表など、現実のデータの多くは「名前 → 値」の形なので、とてもよく使います。

@detail
### 1. 辞書を作る・取り出す
```python
scores = {"たろう": 81, "はなこ": 92}
print(scores["はなこ"])       # 92
```
- `{ }` の中に `キー: 値` をカンマ区切りで並べる
- 取り出すときは `辞書[キー]`（リストの番号の代わりにキー）

### 2. 追加・書き換え・確認
```python
scores["じろう"] = 67         # 新しいキー → 追加
scores["たろう"] = 85         # 既にあるキー → 上書き
print(scores)                 # {'たろう': 85, 'はなこ': 92, 'じろう': 67}
print(len(scores))            # 3（ペアの数）
print("さくら" in scores)      # False（キーがあるか）
```
存在しないキーを `scores["さくら"]` で取り出すと **KeyError**。`scores.get("さくら", 0)` なら、無いときに 0 を返してくれます。

### 3. 辞書をループする
```python
for name in scores:                 # そのまま回すとキーが出てくる
    print(name, scores[name])

for name, s in scores.items():      # .items() でキーと値を同時に
    print(f"{name}: {s}点")
```
▶ 実行結果
```
たろう: 85点
はなこ: 92点
じろう: 67点
```

### 4. 新しい辞書を作って返す（成績→評価の考え方）
```python
def grade_all(scores):
    grades = {}                      # 空の辞書を用意
    for name, s in scores.items():
        if s >= 90:
            grades[name] = "S"       # 同じ名前で評価を入れていく
        else:
            grades[name] = "C"
    return grades

print(grade_all({"たろう": 95, "はなこ": 50}))   # {'たろう': 'S', 'はなこ': 'C'}
```

### 5. 入れ子（ネスト）— リストの中に辞書
```python
travel_log = [
    {"country": "フランス", "visits": 2, "cities": ["パリ", "リヨン"]},
    {"country": "日本", "visits": 5, "cities": ["京都"]},
]
```
外から順に1段ずつたどります。
```python
travel_log[0]                 # 1つ目の辞書（フランス）
travel_log[0]["cities"]       # ["パリ", "リヨン"]
travel_log[0]["cities"][1]    # "リヨン"
```
合計を出すなら、リストを for で回して各辞書の値を足します。
```python
total = 0
for entry in travel_log:
    total += entry["visits"]
print(total)        # 7
```

### 6. 一番大きい値のキーを探す（オークション）
```python
bids = {"たろう": 3000, "はなこ": 5000}
winner = ""
best = 0
for name, amount in bids.items():
    if amount > best:
        best = amount
        winner = name
print(f"落札者は {winner} さん（{best}円）")
```
Day 5 の「チャンピオン方式」を、辞書でやっているだけです。

@pitfalls
- **キーのクォート忘れ** `scores[たろう]` → NameError。文字列のキーは `scores["たろう"]`
- **存在しないキー** → KeyError。`in` で確認するか `.get()`
- **辞書をそのまま for すると値ではなくキーが出る** 値も欲しいなら `.items()`
- **入れ子のたどる順番** 外側から。リストなら番号、辞書ならキー
- **入力した金額を数値にし忘れ** 文字列のまま比べると "900" > "1000" になる（文字の順で比べるため）

@check
Q: `d = {"a": 1, "b": 2}` のあと `d["a"] = 5` を実行すると d は？
- {"a": 1, "b": 2, "a": 5}
* {"a": 5, "b": 2}
- {"a": 6, "b": 2}

Day 8 で少しだけ出てきた **return（戻り値）** を、今日はしっかり身につけます。

関数を「工場」にたとえると、
- **print** は工場の窓から「できました！」と**叫ぶだけ**（外の人には聞こえるが、製品は手元に残らない）
- **return** は**製品を出荷して渡す**（受け取った人がそれを別の工場の材料に使える）

計算した値を「他の計算に使いたい」「別の関数に渡したい」なら return が必要です。

@detail
### 1. return で値を返す
```python
def area(w, h):
    return w * h

a = area(3, 4)          # area(3, 4) の場所が 12 に置き換わるイメージ
print(a)                # 12
print(area(2, 5) + a)   # 10 + 12 = 22
```
呼び出し `area(3, 4)` は、関数が return した値（12）に「化ける」と考えると分かりやすいです。

### 2. print と return の違いを実験
```python
def add_print(a, b):
    print(a + b)        # 表示するだけ

def add_return(a, b):
    return a + b        # 値を返す

x = add_print(2, 3)     # 5 と表示される
y = add_return(2, 3)    # 何も表示されない
print(x)                # None  ← 何も返していないので「なし」
print(y)                # 5
```
return のない関数は **None**（値がない）を返します。演習で「〜を**返す**関数」とあれば必ず return です。

### 3. return でその場で終わる（早期 return）
```python
def format_name(first, last):
    if first == "" or last == "":
        return "名前が入力されていません"    # ← ここで関数は終了
    return f"{first.title()} {last.title()}"
```
return が実行されると、その後ろの行は**実行されません**。「おかしな入力を先にはじく」書き方によく使います。
```python
print(format_name("ada", "LOVELACE"))   # Ada Lovelace
print(format_name("", "x"))             # 名前が入力されていません
```
`.title()` は単語の先頭を大文字、残りを小文字にするメソッドです。

### 4. True / False を返す
```python
def is_leap(year):
    return year % 4 == 0 and (year % 100 != 0 or year % 400 == 0)
```
条件式そのものが True / False なので、if を書かずにそのまま return できます。

### 5. 関数の中で別の関数を使う
```python
def days_in_month(year, month):
    days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
    if month == 2 and is_leap(year):    # is_leap の戻り値（True/False）で判定
        return 29
    return days[month - 1]               # 1月は [0] なので month - 1
```

### 6. docstring（関数の説明書き）
```python
def area(w, h):
    """長方形の面積を返す"""
    return w * h
```
関数の最初の行に `""" """` で書いた説明は、エディタで関数名にカーソルを合わせると表示されます。

### 7. 関数を辞書に入れる（電卓の部品）
```python
def add(a, b):
    return a + b
def subtract(a, b):
    return a - b

operations = {"+": add, "-": subtract}   # () を付けない＝関数そのものを入れる
f = operations["+"]       # f は add 関数
print(f(2, 3))            # 5
print(operations["-"](9, 4))   # 5
```
記号から関数を選べるので、if を4つ並べずに電卓が作れます。

@pitfalls
- **return の代わりに print** → 呼び出し側には None が返り、テストが通らない
- **return の後に処理を書く** return より後の行は実行されない
- **days[month] のずれ** 1月は [0]。`days[month - 1]`
- **辞書に関数を入れるとき () を付ける** `{"+": add()}` は「add を実行した結果」になりエラー。`{"+": add}`
- **float で受け取った数の表示** 3 を float にすると 3.0。電卓の表示例（3.0 + 4.0 = 7.0）はそのため
