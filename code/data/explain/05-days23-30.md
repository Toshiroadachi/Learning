カエルが車の行き交う道路を渡るゲームのしくみを作ります。

今日の主役は、**たくさんのオブジェクトをリストで管理する**係です。車は次々に生まれ、左へ進み、画面の外に出たら消えます。この「生まれる・動く・消える」をまとめて担当する **CarManager（車の管理係）** クラスを作ります。

駐車場の係員が「入ってきた車をリストに書き、出ていった車をリストから消す」のと同じイメージです。

@detail
### 1. 役割ごとにクラスを分ける
| クラス | 担当 |
|---|---|
| Player | 自分の位置、上へ進む、ゴールしたか、スタートに戻る |
| Car | 1台の車の位置（x, y） |
| CarManager | 車のリスト、追加・移動・削除、レベルアップ、衝突判定 |

### 2. Player
```python
class Player:
    def __init__(self):
        self.y = -280                 # 画面の下からスタート
    def up(self):
        self.y += 10
    def at_finish(self):
        return self.y > 280           # 上端を越えたら True
    def go_start(self):
        self.y = -280
```

### 3. Car と CarManager
```python
class Car:
    def __init__(self, x, y):
        self.x = x
        self.y = y

class CarManager:
    def __init__(self):
        self.cars = []                # 最初は車なし
        self.speed = 5
    def add_car(self, x, y):
        self.cars.append(Car(x, y))   # Car を作ってリストに入れる
```

### 4. 全部の車を動かし、画面外の車を消す
```python
def move_cars(self):
    for c in self.cars:
        c.x -= self.speed                          # 左へ進む
    self.cars = [c for c in self.cars if c.x >= -320]   # 画面内の車だけ残す
```
2行目は「**リスト内包表記**」（Day 26 で詳しく）。普通の for で書くと次と同じです。
```python
remaining = []
for c in self.cars:
    if c.x >= -320:
        remaining.append(c)
self.cars = remaining
```
> for で回している最中のリストから `remove` すると、要素が詰まって1台飛ばしてしまうことがあります。「残すものだけで新しいリストを作る」のが安全です。

### 5. 衝突判定
プレイヤーの x は常に 0 とします。車とプレイヤーが「横に 25 未満、縦に 15 未満」の近さなら衝突。
```python
def collides(self, player):
    for c in self.cars:
        if abs(c.x - 0) < 25 and abs(c.y - player.y) < 15:
            return True               # 1台でもぶつかっていれば True
    return False                      # 全部見てぶつかっていなければ False
```
`any()` を使うと1行で書けます。
```python
return any(abs(c.x) < 25 and abs(c.y - player.y) < 15 for c in self.cars)
```
any は「1つでも True があれば True」を返す関数です。

### 6. ランダムな出現とレベルアップ
```python
if random.randint(1, 6) == 1:        # 6回に1回だけ車を作る
    manager.add_car(300, random.randint(-250, 250))

if player.at_finish():
    player.go_start()
    manager.level_up()               # speed += 10 で難しくなる
```

@pitfalls
- **ループ中のリストから remove** 1台飛ばしが起きる → 残す車で新しいリストを作る
- **x < -320 と x >= -320 の向き** 「残す」条件は画面内（x >= -320）
- **collides の return True/False の位置** False をループの中に書くと、1台目しか調べない
- **Car(x, y) を作らずに座標だけ入れる** 車の x を c.x で読めなくなる
- **speed の初期値・増え方** 問題文どおり（5 から、level_up で +10）

@check
Q: `[n for n in [3, -1, 4] if n > 0]` の結果は？
- [3, -1, 4]
* [3, 4]
- [-1]
- [True, False, True]
E: 条件 n > 0 を満たすものだけを集めます。

Q: `any([False, True, False])` の結果は？
* True
- False
- 1
- [True]
E: 1つでも True があれば True です。

Q: 車のリストを for で回しながら、画面外の車を remove すると起きやすい問題は？
- 動作が速くなりすぎる
* 要素が詰まって、次の車を調べずに飛ばしてしまう
- 車が増える
- 必ずエラーになる
E: 回している最中にリストが縮むと、次の要素がずれてチェック漏れが起きます。

@steps d23-1
1. `Player`：y = -280、`up` で +10、`at_finish` は `return self.y > 280`、`go_start` で -280 に戻す
2. `Car(x, y)`：x と y を属性に保存するだけ
3. `CarManager`：`cars = []`、`speed = 5`、`add_car` で `Car(x, y)` を append
4. `move_cars`：全車の x を speed 減らした後、`self.cars = [c for c in self.cars if c.x >= -320]`
5. `level_up` は speed += 10。`collides(player)` は1台でも条件を満たせば True

これまでのプログラムは、終了すると変数の中身がすべて消えていました。**ファイル**に書き込めば、データを**保存して次回も使える**ようになります。

ファイル操作は「**ノートを開く → 読む/書く → 閉じる**」の3ステップです。今日は、名前のリストとひな形（テンプレート）から招待状を何通も作る「差し込み印刷」を作ります。Word の差し込み印刷と同じことが、数行のプログラムでできます。

@detail
### 1. ファイルに書く
```python
with open("memo.txt", "w") as f:
    f.write("こんにちは\n")
    f.write("2行目\n")
```
- `open(ファイル名, モード)` でファイルを開く
- モード：`"w"` 書き込み（**上書き**）、`"a"` 追記（最後に足す）、`"r"` 読み込み（省略時）
- `with … as f:` の f が開いたファイル。ブロックを抜けると**自動で閉じる**
- write は改行を自動で付けないので、必要なら `\n`

### 2. ファイルを読む
```python
with open("memo.txt") as f:
    text = f.read()                  # 全部を1つの文字列で
print(text)
```
1行ずつ処理したいときは、ファイルを直接 for で回します。
```python
with open("names.txt") as f:
    for line in f:
        name = line.strip()          # 行末の改行 \n を取り除く
        print(f"[{name}]")
```
`strip()` を忘れると、名前の後ろに改行が付いたまま使ってしまいます。

### 3. テンプレートの差し込み
```python
template = "[name] 様\nパーティーにご招待します。"
letter = template.replace("[name]", "たろう")
print(letter)
```
▶ 実行結果
```
たろう 様
パーティーにご招待します。
```

### 4. フォルダとパス
```python
import os
os.makedirs("output", exist_ok=True)     # フォルダを作る（既にあってもエラーにしない）
with open("output/たろう.txt", "w") as f: # output フォルダの中のファイル
    f.write("…")
print(os.listdir("output"))              # フォルダの中身の一覧
```
- **相対パス** `output/たろう.txt`：今いる場所から見た位置
- **絶対パス** `/home/user/output/たろう.txt`：一番上から見た位置

### 5. ファイルがあるか確認する
```python
if os.path.exists("high_score.txt"):
    with open("high_score.txt") as f:
        best = int(f.read())             # ファイルの中身は文字列なので int に
else:
    best = 0
```
読み込んだ内容は**いつも文字列**です。数として比べるなら int()。書き込むときは逆に `str(score)` で文字列にします。

### 6. 全体の流れ（差し込み印刷）
```python
template = open("template.txt").read()
count = 0
for line in open("names.txt"):
    name = line.strip()
    with open(f"output/{name}.txt", "w") as f:
        f.write(template.replace("[name]", name))
    count += 1
print(f"{count}件作成しました")
```
> このアプリでは、作ったファイルはブラウザの中の仮想的な場所に保存されます（スマホ本体には残りません）。

@pitfalls
- **"w" で既存の内容が消える** 上書きモード。足したいなら "a"
- **strip() 忘れ** ファイル名に改行が入る・比較が一致しない
- **フォルダを作らずに書き込む** FileNotFoundError → `os.makedirs(…, exist_ok=True)`
- **数値をそのまま write** `f.write(100)` は TypeError → `str(100)`
- **読んだ文字列をそのまま比較** "90" と 100 は比べられない → int()

@check
Q: `open("a.txt", "w")` で開いて書き込むと、元の内容は？
* 消えて、新しい内容だけになる
- 元の内容の後ろに追加される
- 元の内容が先頭に残る
- エラーになる
E: "w" は上書き。追記したいなら "a" を使います。

Q: `"  たろう\n".strip()` の結果は？
- "  たろう"
* "たろう"
- "たろう\n"
- "たろう "
E: strip は前後の空白と改行を取り除きます。

Q: `with open(...) as f:` を使う一番の利点は？
- 速く読める
* ブロックを抜けると自動でファイルが閉じられる
- ファイルが自動で作られる
- 文字化けしない
E: 閉じ忘れを防げるので、ファイル操作の基本の書き方です。

@steps d24-1
1. `os.makedirs("output", exist_ok=True)` で保存先のフォルダを作る
2. テンプレートを `open("template.txt").read()` で読み込む
3. `for line in open("names.txt"):` で1行ずつ、`name = line.strip()`
4. `open(f"output/{name}.txt", "w")` に `template.replace("[name]", name)` を書き、件数を数える
5. ループの後で `{件数}件作成しました`

@steps d24-2
1. `os.path.exists("high_score.txt")` なら読み込んで `int(...)`、なければ best = 0
2. `if score > best:` なら "w" で `str(score)` を書き込み、best = score
3. `return best`（更新されていれば新しい値、そうでなければ元の最高点）

**内包表記（ないほうひょうき）**は、「for ループでリストを作る」いつものパターンを**1行で書く**書き方です。

日本語で言うと「**numsの各nについて、n×2 を集めたリスト**」── これをそのまま `[n * 2 for n in nums]` と書けます。最初は呪文のように見えますが、普通の for ループとの対応が分かれば読めるようになります。

@detail
### 1. for ループとの対応
いつもの書き方：
```python
nums = [1, 2, 3, 4]
doubled = []
for n in nums:
    doubled.append(n * 2)
print(doubled)        # [2, 4, 6, 8]
```
内包表記：
```python
doubled = [n * 2 for n in nums]
```
対応関係はこうです。
```
[ n * 2       for n in nums ]
  ↑ 集めるもの   ↑ いつもの for の部分（コロンなし）
```
**「何を集めるか」を先に書き、その後ろに for を書く**のがポイントです。

### 2. 条件で絞り込む（if を後ろに）
```python
evens = [n for n in nums if n % 2 == 0]      # [2, 4]
```
for ループで書くと：
```python
evens = []
for n in nums:
    if n % 2 == 0:
        evens.append(n)
```
```
[ n    for n in nums    if n % 2 == 0 ]
 集める   どこから          条件（合うものだけ）
```

### 3. 変換と絞り込みを同時に
```python
words = ["apple", "fig", "banana"]
long_upper = [w.upper() for w in words if len(w) >= 5]
print(long_upper)     # ['APPLE', 'BANANA']
```
「5文字以上の単語だけ選んで、大文字にして集める」。

### 4. range からも作れる
```python
squares = [n ** 2 for n in range(1, 6)]    # [1, 4, 9, 16, 25]
```

### 5. 辞書内包表記
`{ }` で囲み、`キー: 値` の形で集めると辞書になります。
```python
words = ["apple", "fig"]
lengths = {w: len(w) for w in words}       # {'apple': 5, 'fig': 3}

scores = {"A": 80, "B": 45}
passed = {k: v for k, v in scores.items() if v >= 60}   # {'A': 80}
```

### 6. 2つのリストを組み合わせる zip
```python
letters = ["A", "B", "C"]
codes = [".-", "-...", "-.-."]
MORSE = {l: c for l, c in zip(letters, codes)}
print(MORSE)      # {'A': '.-', 'B': '-...', 'C': '-.-.'}
```
`zip` は2つのリストを「同じ番号同士」でペアにします。

### 7. 内包表記で作った結果を使う
```python
word = "HI"
print(" ".join([MORSE[ch] for ch in word]))
```
1文字ずつ符号に変えたリストを作り、空白でつないで表示しています。

> 読みにくくなるほど長い条件や、途中で print したい処理は、普通の for ループの方が分かりやすいこともあります。「1行で読めるとき」に使いましょう。

@pitfalls
- **順番を逆に書く** `[for n in nums n * 2]` は文法エラー。「集めるもの」が先
- **if と else** 絞り込みの if は後ろ。`[x if 条件 else y for x in …]` は「変換の if」で、意味も位置も違う
- **辞書内包表記のコロン** `{w: len(w) for w in words}`。カンマにしないこと
- **小文字のまま辞書を引く** MORSE は大文字のキー → `.upper()` してから引く
- **isalpha()** 空白や数字が入ると False。入力チェックに使える

@check
Q: `[x * 10 for x in [1, 2, 3]]` の結果は？
- [1, 2, 3, 10]
* [10, 20, 30]
- 60
- [[10], [20], [30]]
E: 各 x に 10 を掛けたものを集めます。

Q: `[w for w in ["a", "bb", "ccc"] if len(w) > 1]` の結果は？
- ["a"]
* ["bb", "ccc"]
- [2, 3]
- ["a", "bb", "ccc"]
E: 長さが1より大きいものだけ残ります。

Q: `{n: n * n for n in [2, 3]}` の結果は？
- [4, 9]
* {2: 4, 3: 9}
- {4: 2, 9: 3}
- {2, 3, 4, 9}
E: キーが n、値が n×n の辞書になります。

@steps d26-1
1. squares：`[n ** 2 for n in range(1, 11)]`（10 を含めるので 11）
2. long_words：`[w.upper() for w in words if len(w) >= 5]`
3. word_len：`{w: len(w) for w in words}`
4. common：`[n for n in a if n in b]`（a の順番のまま、b にもあるものだけ）

@steps d26-2
1. `MORSE = {l: c for l, c in zip(letters, codes)}` で辞書を作る

4. `" ".join([MORSE[ch] for ch in word])` を表示して `break`

ラーメン屋の注文にたとえると、
- **デフォルト値**：何も言わなければ「麺ふつう・味ふつう」（指定したところだけ変えられる）
- **\*args**：トッピングを**いくつでも**注文できる（数が決まっていない）
- **\*\*kwargs**：「麺=かため」「味=こいめ」のように、**名前付きの注文をいくつでも**

ライブラリのドキュメントを読むと、この書き方がたくさん出てきます。仕組みを知っておくと、他人の関数の使い方がぐっと読みやすくなります。

@detail
### 1. デフォルト値（復習）
```python
def make_tea(kind="緑茶", sugar=0):
    return f"{kind}（砂糖{sugar}）"

print(make_tea())                  # 緑茶（砂糖0）
print(make_tea("紅茶"))             # 紅茶（砂糖0）
print(make_tea(sugar=2))           # 緑茶（砂糖2）← 名前を指定すれば途中を飛ばせる
```

### 2. *args — いくつでも受け取る（タプルにまとまる）
```python
def add(*args):
    print(args)          # (1, 2, 3) ← タプルとして届く
    return sum(args)

print(add(1, 2, 3))      # 6
print(add(5))            # 5
print(add())             # 0
```
`*` を付けた引数は、渡された値を**全部まとめてタプル**にして受け取ります。名前は args でなくても構いません（`*values` など）。

### 3. **kwargs — 名前付きでいくつでも（辞書にまとまる）
```python
def profile(name, **kwargs):
    print(name, kwargs)

profile("たろう", age=30, city="大阪")
```
▶ 実行結果
```
たろう {'age': 30, 'city': '大阪'}
```
`**` を付けた引数は、`名前=値` で渡されたものを**辞書**で受け取ります。無いかもしれない項目は `kwargs.get("city", "不明")` で安全に取り出せます。

### 4. キーワード専用引数（* の後ろ）
```python
def convert(value, *, from_unit="km", to_unit="mile"):
    ...

convert(10, from_unit="mile", to_unit="km")    # OK
convert(10, "mile", "km")                      # TypeError（名前を付けないとダメ）
```
引数リストの途中に `*` だけを書くと、**それより後ろは名前を付けないと渡せない**引数になります。「どっちがどっちか分からなくなる」引数の取り違えを防げます。

### 5. 単位変換の考え方（いったん共通の単位に）
```python
TO_KM = {"km": 1, "mile": 1.609344, "m": 0.001}   # 1単位が何 km か
value = 3                                        # 3 mile を m に変えたい
km = value * TO_KM["mile"]                       # まず km に：4.828032
m = km / TO_KM["m"]                              # 次に m に：4828.032
```
どの単位どうしでも「一度 km にしてから、目的の単位に直す」だけで済みます。

### 6. アンパック（逆向き：まとめて渡す）
```python
nums = [1, 2, 3]
print(add(*nums))          # add(1, 2, 3) と同じ → 6

opts = {"kind": "紅茶", "sugar": 1}
print(make_tea(**opts))    # make_tea(kind="紅茶", sugar=1) と同じ
```
呼び出し側で `*` / `**` を付けると、リストや辞書を「ばらして」渡せます。

### 7. 余分な .0 を消す書式 :g
```python
print(f"{12.5:g}")    # 12.5
print(f"{12.0:g}")    # 12
```

@pitfalls
- **キーワード専用引数を位置で渡す** `*` の後ろは `名前=値` で
- **args を足すときに sum を使わず + でつなぐ** タプルは sum でまとめて合計できる
- **round の桁** `round(値, digits)`。digits を引数から使う
- **単位の換算の向き** 「km にするときは掛ける、km から戻すときは割る」
- **total の表示形式** `"12.5 km"`（数字と単位の間に半角スペース）

- (1, 2)

- "a=1, b=2"
E: ** で受け取ると、名前と値の辞書になります。

今日のテーマは**時間の計算**です。人間は「305秒＝5分5秒」と自然に考えますが、プログラムでは「60で割った商と余り」で計算します。また、「9時から25分後は何時？」のような時刻の計算は、日付と時刻の専門家である `datetime` に任せます。

@detail
### 1. 秒 → 分と秒（divmod）
```python
m, s = divmod(305, 60)     # 305 ÷ 60 = 5 余り 5
print(m, s)                # 5 5
```
`divmod(a, b)` は「a // b（商）」と「a % b（余り）」を一度に返します。

### 2. 0埋めで2桁にする
```python
print(f"{5:02d}")          # 05
print(f"{12:02d}")         # 12
print(f"{m:02d}:{s:02d}")  # 05:05
```
`:02d` は「整数（d）を、2桁で、足りなければ 0 で埋める」。

60分を超えても「分」で表すなら、時間に直さずそのまま：
```python
m, s = divmod(3725, 60)    # 62, 5
print(f"{m:02d}:{s:02d}")  # 62:05
```

### 3. 時刻を扱う datetime と timedelta
```python
from datetime import datetime, timedelta
start = datetime(2026, 11, 15, 9, 0)        # 2026/11/15 9:00
end = start + timedelta(minutes=25)         # 25分後
print(end.strftime("%H:%M"))                # 09:25
```
- `timedelta(minutes=25)` は「25分という長さ」
- 時刻 ＋ 長さ ＝ 新しい時刻（59分＋5分のような繰り上がりも自動）
- `strftime("%H:%M")` で「時:分」の文字列に（%H は 2桁の時、%M は 2桁の分）

### 4. 文字列 → 時刻（strptime）
```python
t = datetime.strptime("9:00", "%H:%M")      # 入力された "9:00" を時刻に
print(t.strftime("%H:%M"))                  # 09:00
```
**strp**time は文字列を読む（parse）、**strf**time は文字列に整える（format）、と覚えましょう。

### 5. スケジュールを作る考え方
```python
t = datetime.strptime("9:00", "%H:%M")
n = 2
for i in range(1, n + 1):
    end = t + timedelta(minutes=25)
    print(f"{t.strftime('%H:%M')}-{end.strftime('%H:%M')} 作業{i}")
    t = end                                  # 次の開始は今の終わり
    if i < n:                                # 最後の作業の後は休憩なし
        rest = 20 if i % 4 == 0 else 5       # 4回ごとに長い休憩
        end = t + timedelta(minutes=rest)
        print(f"{t.strftime('%H:%M')}-{end.strftime('%H:%M')} 休憩")
        t = end
print(f"終了 {t.strftime('%H:%M')}")
```
「今の時刻 t」を1つの変数で持ち、作業・休憩のたびに進めていきます。

> PC で GUI 版を作るときは、tkinter の `window.after(1000, 関数)` で1秒ごとにカウントダウンを更新します。時間の計算部分は今日作ったものと同じです。

@pitfalls
- **f文字列の中のクォート** 外が `"` なら中の `strftime('%H:%M')` は `'`
- **%M と %m** %M は分、%m は月
- **最後の作業の後に休憩を入れる** `if i < n:` で防ぐ
- **長い休憩の判定** 4回目・8回目…の後 → `i % 4 == 0`
- **時刻を進め忘れる** `t = end` がないと、毎回同じ時刻が表示される

プログラムは、思いがけない入力やファイルがないなどの理由で**エラー（例外）**が起きると、その場で止まってしまいます。

**例外処理（try / except）**は「**転ばぬ先の杖**」です。「ここでこういうエラーが起きるかもしれない。起きたらこうする」と前もって書いておくことで、プログラムを止めずに対処できます。

たとえば「数字を入力してください」と言っているのに「abc」と入力された ── そんなとき、エラーで止まるのではなく「数字で入力してください」と言って聞き直す、という親切なプログラムが書けるようになります。

@detail
### 1. まず、エラーで止まる例
```python
n = int(input("数: "))       # 「abc」と入力すると…
print(n * 2)
```
▶ 実行結果
```
ValueError: invalid literal for int() with base 10: 'abc'
```
int() に数字以外の文字を渡すと **ValueError** が起き、そこでプログラムが止まります。

### 2. try / except で受け止める
```python
try:
    n = int(input("数: "))
    print(n * 2)
except ValueError:
    print("数字を入力してください")
print("終わり")
```
- **try:** の中を実行してみる
- 途中で **ValueError** が起きたら、try の残りを飛ばして **except ValueError:** の中を実行
- エラーが起きなければ except は飛ばす
- どちらの場合も、その後のプログラムは続く（"終わり" が表示される）

### 3. else と finally
```python
try:
    n = int(input("数: "))
except ValueError:
    print("数字を入力してください")
else:
    print("OK:", n)          # エラーが起きなかったときだけ
finally:
    print("おしまい")         # エラーがあってもなくても必ず
```

### 4. 正しい値が来るまで聞き直す（while と組み合わせ）
```python
while True:
    try:
        n = int(input("1〜10: "))
    except ValueError:
        print("数字で入力してください")
        continue                       # 先頭に戻って聞き直す
    if 1 <= n <= 10:
        break                          # 正しい値ならループを抜ける
    print("1〜10 の範囲で入力してください")
print(f"あなたの数は {n}")
```
「型のチェック（数字か）」は例外で、「範囲のチェック」は if で行っています。

### 5. よく出る例外と使いどころ
| 例外 | 起きるとき |
|---|---|
| ValueError | `int("abc")` のように値が変換できない |
| KeyError | 辞書に無いキーを使った |
| IndexError | リストの範囲外 |
| FileNotFoundError | ファイルが無い |
| ZeroDivisionError | 0 で割った |
```python
post = {"text": "こんにちは"}
try:
    likes = post["likes"]
except KeyError:
    likes = 0                  # 無いときは 0 とみなす
```

### 6. 自分から例外を起こす raise
「この値はおかしい」と関数の側で判断したとき、自分で例外を起こして知らせられます。
```python
def set_age(age):
    if age < 0:
        raise ValueError("年齢は0以上")
    return age

set_age(-5)     # ValueError: 年齢は0以上
```
呼び出した側は、try / except でこれを受け止められます。

### 7. 何でも捕まえる except: は避ける
```python
try:
    ...
except:          # どんなエラーも黙って捕まえる
    pass
```
これをすると、スペルミスなどの本当のバグまで隠れて見つけにくくなります。**起きることが分かっている種類だけ**を指定しましょう。

@pitfalls
- **try の範囲が広すぎる** 関係ない行まで入れると、別の原因のエラーまで同じ扱いになる
- **例外の種類の間違い** int() の失敗は ValueError、辞書のキーは KeyError
- **except の後に何もしない** 少なくともメッセージを出すか、代わりの値を入れる
- **raise の書き方** `raise ValueError("メッセージ")`（return ではない）
- **continue の位置** except の中で continue すると、その後の範囲チェックを飛ばして聞き直せる

Day 24 ではテキストファイルに文字を保存しました。でも、辞書やリストのような**形のあるデータ**をそのまま保存したいことがよくあります。

**JSON（ジェイソン）**は、辞書やリストを**そのままの形でテキストに書ける形式**です。「サイト名 → {メールアドレス, パスワード}」のような入れ子の辞書も、保存して、次に起動したときに元通り読み込めます。Web の API がやり取りするデータもほとんどが JSON なので、一生使える知識です。

今日は例外処理（Day 29）と組み合わせて、簡単なパスワード管理ツールを作ります。

@detail
### 1. JSON の見た目
```json
{
  "gmail": {"email": "me@example.com", "password": "abc123"},
  "amazon": {"email": "me@example.com", "password": "xyz789"}
}
```
Python の辞書とほぼ同じ見た目です（文字列は必ず " で囲む、True は true になる、などの細かい違いはあります）。

### 2. 保存する json.dump
```python
import json
data = {"gmail": {"email": "me@example.com", "password": "abc123"}}
with open("vault.json", "w") as f:
    json.dump(data, f, indent=2, ensure_ascii=False)
```
- `json.dump(保存するデータ, ファイル)`
- `indent=2` で人が読みやすいように字下げ
- `ensure_ascii=False` で日本語をそのまま保存（付けないと あ のような記号になる）

### 3. 読み込む json.load
```python
with open("vault.json") as f:
    loaded = json.load(f)
print(loaded["gmail"]["password"])     # abc123
```
読み込んだ結果は、元どおりの**辞書**です。

### 4. 更新は「読む → 変える → 書く」
JSON ファイルの一部だけを書き換えることはできません。
```python
with open("vault.json") as f:
    data = json.load(f)                     # ① 全部読む
data["amazon"] = {"email": "…", "password": "…"}   # ② 辞書を変更
with open("vault.json", "w") as f:
    json.dump(data, f, indent=2, ensure_ascii=False)  # ③ 全部書き直す
```

### 5. 最初はファイルが無い → 例外処理
初めて使うときは vault.json がまだありません。読もうとすると FileNotFoundError になります。
```python
try:

except FileNotFoundError:
```

### 6. 検索（2種類の「無い」を区別する）
```python
def find(site):
    try:
        with open("vault.json") as f:
            data = json.load(f)
    except FileNotFoundError:
        return "データがありません"            # ファイル自体が無い
    try:
        entry = data[site]
    except KeyError:
        return f"{site} は登録されていません"   # ファイルはあるが、そのサイトが無い
    return f"email: {entry['email']} / password: {entry['password']}"
```

「ファイルが無い」と「サイトが無い」で、利用者に返すメッセージを分けています。

### 7. パスワードを作る

```python
import random, string
```
