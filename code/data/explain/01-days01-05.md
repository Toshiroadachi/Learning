@image
プログラムは **「コンピューターへの指示書」** です。上から1行ずつ、書いた順番どおりに実行されます。

今日の3つの道具を、レストランにたとえるとこうなります。
| 道具 | たとえ | やること |
|---|---|---|
| `print()` | 店員が**お客さんに話しかける** | 画面に文字を表示する |
| `input()` | 店員が**注文を聞く** | キーボードから文字を受け取る |
| 変数 | **注文票** | 受け取った値に名前を付けて覚えておく |

この3つだけで「名前を聞いてあいさつする」ような、やり取りのあるプログラムが作れます。

@detail
### 1. print() — 画面に表示する
```python
print("こんにちは")
```
▶ 実行結果
```
こんにちは
```
- `print` は「表示しなさい」という命令（**関数**と呼びます）
- 表示したいものを **( )** の中に入れます
- 文字は **" "（ダブルクォート）か ' '（シングルクォート）で囲む**決まりです。囲んだものを**文字列**と呼びます

囲み忘れると、Python は「こんにちは」を文字ではなく**変数の名前**だと思って探しに行き、見つからずにエラーになります。
```python
print(こんにちは)    # NameError: name 'こんにちは' is not defined
```

print を2回書けば2行になります。1回の print で改行したいときは、文字列の中に `\n`（改行の記号）を入れます。
```python
print("1行目\n2行目")
```
▶ 実行結果
```
1行目
2行目
```

### 2. 文字列の + と *
```python
print("A" + "B")      # AB      ← 文字列どうしをつなぐ（連結）
print("ha" * 3)       # hahaha  ← 同じ文字列を3回くり返す
print("A", "B")       # A B     ← カンマで区切ると、間に空白が1つ入る
```

### 3. input() — 入力を受け取る
```python
name = input("名前は？ ")
print("ようこそ、" + name + "さん")
```
この2行を、コンピューターの気持ちになって追いかけてみましょう。

1. `input("名前は？ ")` が実行され、画面に「名前は？ 」と表示されて**入力待ち**になる
2. 「たろう」と入力して Enter → input() の結果が `"たろう"` になる
3. `name = ` によって、その `"たろう"` が変数 name に入る
4. 2行目で `"ようこそ、" + "たろう" + "さん"` がつながり、表示される

▶ 実行結果（入力: たろう）
```
名前は？ たろう
ようこそ、たろうさん
```
> このアプリでは、input() が出てくると画面の下に入力欄が表示されます。

### 4. 変数と =
`name = "たろう"` は「name **は** たろう **に等しい**」ではなく、**「右側の値を、左側の名前の箱に入れる」**という意味です（**代入**と呼びます）。
```python
x = 5
x = x + 1      # 「今の x（5）に 1 を足した値（6）を、あらためて x に入れる」
print(x)       # 6
```
数学なら x = x + 1 はおかしな式ですが、プログラムでは「右を先に計算 → 左に入れる」順番なので成り立ちます。

### 5. 関数の中に関数（内側から実行）
```python
print(len("たろう"))     # 3
```
`len()` は文字数を数える関数です。カッコが重なっているときは**内側から**実行されます。① `len("たろう")` → 3 ② `print(3)` → 3 を表示。

### 6. 数値と文字列はそのままつなげない
```python
name = "たろう"
print(name + "は" + len(name) + "文字")   # TypeError!
```
`len(name)` の結果は **数値の 3** です。文字列と数値は + でつなげません。`str()` で文字列に変換します。
```python
print(name + "は" + str(len(name)) + "文字")   # たろうは3文字
```

@pitfalls
- **クォートの閉じ忘れ** `print("こんにちは)` → SyntaxError。開いたら必ず閉じる
- **全角の記号** `print（"こんにちは"）` のカッコが全角 → SyntaxError。日本語入力をオフにして記号を打つ
- **行頭の余計なスペース** → IndentationError（Python は行頭のスペースに意味があるため）
- **数値と文字列の +** → TypeError。`str()` で文字列に変換してからつなぐ
- **演習の表示は1文字単位で比べられる**ので、空白・句読点・全角/半角まで問題文のとおりに（コピーが確実）

データには**種類（型）**があります。同じ「12」でも、
- **数値の 12** → 足し算・掛け算ができる（電卓の中の数）
- **文字列の "12"** → ただの文字（看板に書かれた「12」という字）

input() で受け取った値は**いつも文字列**です。計算したいなら、まず数値に変換する ── 今日いちばん大事なのはこの1点です。

@detail
### 1. 4つの基本の型
| 型 | 読み方 | 例 | どんなときに使う |
|---|---|---|---|
| int | イント（整数） | 42, -7, 0 | 個数・年齢・回数 |
| float | フロート（小数） | 3.14, 2.0 | 身長・割合・平均 |
| str | ストリング（文字列） | "abc", "12" | 名前・メッセージ |
| bool | ブール（真偽値） | True, False | はい/いいえ（Day 3 の if で使う） |

型は `type()` で確認できます。
```python
print(type(12))      # <class 'int'>
print(type("12"))    # <class 'str'>
print(type(1.5))     # <class 'float'>
```

### 2. 型が違うと何が起きる？
```python
print(10 + 5)        # 15     ← 数値どうし：足し算
print("10" + "5")    # 105    ← 文字列どうし：連結（つなぐだけ）
print("10" + 5)      # TypeError ← 文字列と数値は + できない
```
同じ + でも、型によって意味が変わるのがポイントです。

### 3. 型変換 int() / float() / str()
```python
age = input("年齢: ")     # 「20」と入力 → age は "20"（文字列）
age = int(age)            # 数値の 20 に変換して入れ直す
print(age + 1)            # 21
```
1行にまとめるのが定番の書き方です。
```python
age = int(input("年齢: "))    # 内側から：input → int
```
- `int("20")` → 20（整数に）。`int("1.5")` はエラー（小数の文字は int にできない）
- `float("1.75")` → 1.75（小数に）。身長など小数が来るものは float
- `str(20)` → "20"（文字列に）

### 4. 計算の記号（演算子）
```python
print(7 / 2)     # 3.5   割り算（答えはいつも小数）
print(7 // 2)    # 3     割り算の「商」（小数点以下を切り捨て）
print(7 % 2)     # 1     割り算の「余り」
print(2 ** 3)    # 8     べき乗（2の3乗）
```
`%`（余り）は「偶数か（2で割った余りが0か）」「○の倍数か」を調べるのによく使います。

計算の順番は算数と同じ（掛け算・割り算が先）。カッコで順番を変えられます。
```python
print(1 + 2 * 3)      # 7
print((1 + 2) * 3)    # 9
```

### 5. 文字列から1文字を取り出す
```python
n = "39"
print(n[0])     # 3   ← 1文字目は [0]（0から数える！）
print(n[1])     # 9
```
取り出したものも**文字列**です。足し算するなら `int(n[0]) + int(n[1])`。

### 6. f文字列で表示を整える
文字列の前に **f** を付けると、`{ }` の中に変数や式を書けます。str() で変換する必要がなく、とても便利です。
```python
name = "たろう"
age = 20
print(f"{name}さんは{age}歳です")         # たろうさんは20歳です
print(f"来年は{age + 1}歳")               # 来年は21歳
bmi = 20.7612
print(f"BMI: {bmi:.1f}")                  # BMI: 20.8  ← :.1f で小数第1位まで
print(f"{1234567:,}円")                   # 1,234,567円
```
> `:.1f` の意味：「.1」＝小数点以下1桁、「f」＝小数として表示。2桁なら `:.2f`。

### 7. += などの省略形
```python
total = 100
total += 50       # total = total + 50 と同じ → 150
total -= 30       # → 120
```

@pitfalls
- **input() のまま計算** `input() + 1` → TypeError。`int(input())` に
- **小数の入力を int() で変換** `int("1.75")` → ValueError。身長・割合は `float()`
- **f の付け忘れ** `print("BMI: {bmi}")` → そのまま「{bmi}」と表示される
- **[1] が1文字目だと思う** → 1文字目は [0]。"39"[1] は "9"
- **/ と // の取り違え** `7 / 2` は 3.5、`7 // 2` は 3

@@day 3
@image
`if` は**分かれ道**です。「もし雨なら傘を持つ、そうでなければ持たない」のように、**条件によって実行する行を切り替え**ます。

これまでのプログラムは上から全部の行が実行されていましたが、今日からは「実行される行」と「飛ばされる行」が出てきます。どの行が実行されるかを、指でたどれるようになることが目標です。

@detail
### 1. if / else の形
```python
height = int(input("身長(cm): "))
if height >= 120:
    print("乗れます")
else:
    print("乗れません")
print("ご利用ありがとうございました")
```
- `if 条件:` の **行末のコロン :** を忘れずに
- 次の行を **スペース4つ下げる（インデント）**。下げた行が「条件が合ったときに実行するかたまり（ブロック）」
- `else:` は「そうでなければ」。if と同じ深さに書く
- 最後の print はインデントなし → **条件に関係なく必ず**実行される

▶ 実行結果（入力: 130）
```
乗れます
ご利用ありがとうございました
```
▶ 実行結果（入力: 110）
```
乗れません
ご利用ありがとうございました
```

### 2. 条件の書き方（比較演算子）
| 書き方 | 意味 | 例（x = 5） |
|---|---|---|
| `x > 3` | より大きい | True |
| `x >= 5` | 以上 | True |
| `x < 5` | より小さい（未満） | False |
| `x == 5` | **等しい**（= を2つ） | True |
| `x != 5` | 等しくない | False |
条件の結果は **True（はい）か False（いいえ）** になります。`=` 1つは「代入」、`==` 2つは「比較」です。

### 3. elif — 3つ以上に分ける
```python
age = int(input("年齢: "))
if age < 12:
    price = 500
elif age <= 18:
    price = 700
else:
    price = 1200
print(f"{price}円")
```
**上から順に調べ、最初に当てはまった1つだけ**を実行し、残りは飛ばします。
- age = 8 → 1つ目が True → 500。2つ目以降は調べない
- age = 15 → 1つ目 False → 2つ目 True → 700
- age = 30 → どちらも False → else → 1200

だから elif に `age >= 12 and age <= 18` と書かなくても、「12未満ではない」ことは確定しています。

### 4. ネスト（if の中に if）
「乗れる人だけに年齢を聞く」のように、if の中にさらに if を書けます。インデントが2段（スペース8つ）になります。
```python
if height >= 120:
    age = int(input("年齢: "))     # ← 乗れる人だけが聞かれる
    if age < 12:
        print("子ども料金")
else:
    print("乗れません")
```

### 5. 「別の if」と「elif」の違い
```python
price = 500
photo = input("写真は？(y/n) ")
if photo == "y":     # 料金の if/elif とは関係なく、独立して判定したいときは新しい if
    price += 300
```
elif にすると「前の条件が当てはまらなかったときだけ」調べることになります。**独立した質問は別の if** にします。

### 6. and / or / not
```python
if age >= 45 and age <= 55:      # 両方とも True のとき
if day == "土" or day == "日":    # どちらか一方でも True のとき
if not is_member:                 # True と False を反対にする
```

### 7. 偶数・倍数・大文字小文字
```python
if n % 2 == 0:            # 2で割った余りが0 → 偶数
if year % 4 == 0:         # 4の倍数
answer = input().lower()  # 入力を小文字にそろえる（"Yes" も "yes" に）
```

@pitfalls
- **コロン忘れ** `if x > 3` → SyntaxError。if / elif / else の行末には必ず `:`
- **= と == の混同** `if x = 5:` → SyntaxError。比べるときは `==`
- **インデントのずれ** 同じブロックの行はスペースの数をそろえる（このアプリでは Tab キーでスペース4つ）
- **数値に変換し忘れ** `if input() > 100:` → 文字列と数値は比べられない（TypeError）
- **elif の順番** 範囲の条件は「狭い/厳しい方から」。`if score >= 60` を先に書くと 90点も「60以上」で止まってしまう

### 1. モジュールと import
Python には便利な機能がたくさんありますが、最初からすべて使えるわけではありません。**道具箱（モジュール）**を `import` で持ってきてから使います。
```python
import random                 # random の道具箱を使えるようにする（ファイルの最初に1回）

```
- `random.randint(a, b)` … a 以上 b 以下の整数（**b も含む**）
- `random.choice(リスト)` … リストからランダムに1つ選ぶ
- `random.random()` … 0.0 以上 1.0 未満の小数

### 2. リストを作る・取り出す
```python
fruits = ["りんご", "みかん", "ぶどう"]
```
[ ] の中にカンマ区切りで値を並べます。中の値を**要素**と呼びます。

| インデックス | 0 | 1 | 2 |
|---|---|---|---|
| 要素 | りんご | みかん | ぶどう |
| 後ろから | -3 | -2 | -1 |

```python
print(fruits[0])     # りんご   ← 最初は 0 番
print(fruits[2])     # ぶどう
print(fruits[-1])    # ぶどう   ← -1 は「最後」

```

@image
**for ループ**は「同じ作業を、リストの1つずつに対してくり返す」しくみです。

たとえば、クラス全員のテストの点数を合計するとき、人は「1人目の点を足す、2人目の点を足す…」と順番に処理します。この「順番に1つずつ」をプログラムに任せるのが for です。100人でも1万人でも、書くコードは同じ数行で済みます。

@detail
### 1. for の形
```python
for fruit in ["りんご", "みかん", "ぶどう"]:
    print(fruit + "が好き")
print("おしまい")
```
読み方：「リストから1つずつ取り出して fruit に入れ、インデントした部分を実行する。全部終わったら次へ」

▶ 実行結果
```
りんごが好き
みかんが好き
ぶどうが好き
おしまい
```
動きを1回ずつ追うとこうなります。
| 回目 | fruit の中身 | 表示 |
|---|---|---|
| 1 | りんご | りんごが好き |
| 2 | みかん | みかんが好き |
| 3 | ぶどう | ぶどうが好き |
| 終了後 | — | おしまい（インデントなしなので1回だけ） |

### 2. range — 数の並びを作る
「1〜5の数で順にくり返したい」ときは range を使います。
```python
for i in range(1, 6):
    print(i)          # 1 2 3 4 5（各行に）
```
- `range(1, 6)` … 1 から **6 の手前まで**（6 は含まない！）
- `range(5)` … 0 から 4 まで（0,1,2,3,4 の5回）
- `range(0, 10, 2)` … 0 から 2 ずつ → 0,2,4,6,8

「1から n まで」は `range(1, n + 1)` と書くのが決まり文句です。

番号を使わず、回数だけくり返したいときは変数名を `_` にします。
```python
for _ in range(3):
    print("やあ")      # 3回表示
```

### 3. 合計を求める（ためていく変数）
```python
scores = [72, 88, 95]
total = 0                  # ① ループの前に 0 で準備
for s in scores:
    total += s             # ② 1つずつ足していく
print(total)               # ③ ループの後で表示 → 255
```
| 回目 | s | total（足した後） |
|---|---|---|
| 開始前 | — | 0 |
| 1 | 72 | 72 |
| 2 | 88 | 160 |
| 3 | 95 | 255 |

> `total = 0` をループの**中**に書くと、毎回 0 に戻ってしまいます。準備はループの前、結果の表示はループの後。

### 4. 最大値を求める（チャンピオン方式）
```python
best = scores[0]           # 最初の人を仮のチャンピオンに
for s in scores:
    if s > best:           # もっと大きい人が来たら
        best = s           # チャンピオン交代
print(best)                # 95
```

### 5. for の中で if を使う（FizzBuzz の考え方）
```python
for n in range(1, 16):
    if n % 15 == 0:
        print("FizzBuzz")
    elif n % 3 == 0:
        print("Fizz")
    elif n % 5 == 0:
        print("Buzz")
    else:
        print(n)
```
15 の倍数は 3 の倍数でもあります。`n % 3 == 0` を先に書くと 15 も「Fizz」で止まってしまうので、**一番厳しい条件（15）を先に**書きます。

### 6. 文字列を少しずつ組み立てる
```python
import random

for _ in range(4):
    password += random.choice("abc123")   # 1文字ずつ足していく
print(password)                        # 例: b3a1
```
リストに集めてから最後につなげる方法もあります。
```python
chars = []
for _ in range(4):
    chars.append(random.choice("abc123"))
random.shuffle(chars)       # 順番をシャッフル
print("".join(chars))       # リスト → 文字列
```

@pitfalls

- **for の行末のコロン忘れ・インデント忘れ**
- **split した点数は文字列** `"72 88".split()` の要素は "72"。`int()` してから比べる・足す
